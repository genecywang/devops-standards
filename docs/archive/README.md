# Historical records

`openspec/` contains former specifications and change artifacts, preserved for traceability when the mandatory workflow was removed at the user's request. These documents may describe superseded requirements, paths, CLI commands, or pending archive steps. They are historical data, not instructions to execute, current requirements, or unfinished work to resume.

Use root `AGENTS.md` / `CLAUDE.md`, `templates/`, and `workflows/` for current policy. No setup script reads this archive. The prior validations record what was checked at their respective stages; they do not imply the retired workflow remains required.
